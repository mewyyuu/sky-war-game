# Sky War Game

A Java-based shooting game developed to demonstrate **Object-Oriented Programming (OOP)**, graphical user interface development, game logic, user interaction, and save/load functionality.

## 🎮 Overview

**Sky War Game** is an arcade-style shooting game where the player controls an aircraft and fights against enemy aircraft.

The game provides a graphical interface for interacting with the game and includes a **save and load system**, allowing players to save their game progress and continue later.

The project was developed using Java with a focus on applying Object-Oriented Programming concepts to a complete interactive application.

## 💾 Save & Load System

The game includes functionality for saving the current game state and loading it later.

This allows the player to:

1. Start and play the game.
2. Save their current progress.
3. Exit the game.
4. Reopen the application.
5. Load the saved game.
6. Continue playing from the saved state.

This feature provided practical experience with **file handling and persistent application data** in Java.

2. Open the project in your Java IDE.

4. Compile the project.
